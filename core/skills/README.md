# Skills

Ressources installables depuis `core/skills`. Les IDs de sélection prennent la forme `core/skills/<nom>` et peuvent être listés avec :

```bash
node dist/cli.js list-resources --target pi
```

Voir aussi [`../../docs/commands.md`](../../docs/commands.md).

- ([brainstorm](./brainstorm/SKILL.md)) : brainstorming session with concecutive questions
- ([code-review](./code-review/SKILL.md)) : code review with tag priority
- ([commit](./commit/SKILL.md)) : commit (and push) your code to the repository
